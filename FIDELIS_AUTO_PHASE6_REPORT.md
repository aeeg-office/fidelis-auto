## 2. Features MISSING From a Minimal Collector-Vehicle Marketplace

A minimal launch (like Fidelis Auto with listings, categories, details, compare, journal/blog, services, submit-listing, admin approval) typically lacks:

1. **Search page + advanced filters** (year, price, make/model, mileage, condition, era, body)
2. **Saved searches** (persist criteria, run again)
3. **Favorites / watchlist** (stored per-user)
4. **Alerts / notifications** (email or push when new matches)
5. **Full vehicle comparison** (side-by-side spec table — note: partially present per context)
6. **Dealer / seller dashboard** (inventory, leads, views, promotion management)
7. **Seller profiles** (public page, listing history, contact)
8. **Verified / trust badges** (identity-verified, dealer-verified, response times)
9. **Vehicle-history / VIN checks** (third-party e.g. CARFAX / home-market equivalent)
10. **Financing calculator / pre-approval**
11. **Insurance** (quote/partner)
12. **Transport & shipping** (quote, logistics partners, in-home delivery)
13. **Offers / buyer–seller messaging**
14. **Sold-history / data + auction mode** (reserve / no-reserve, results archive)
15. **Blog / editorial** (journal already exists — treat as partially present)
16. **Reviews & ratings** (buyer reviews of sellers, dealer ratings)
17. **Analytics** (listing views, buyer behavior, seller reporting)

*Existing on Fidelis already: journal (blog), services marketplace, submit-listing flow, admin approval, categories, compare (partial).*

## 3. Effort vs. Business Value per Missing Feature

Effort = relative implementation cost for an existing Next.js/SaaS listing platform. Value = impact on collector-marketplace stickiness & revenue.

| Feature | Effort | Value | Target precedent (leader) | Rationale |
|---|---|---|---|---|
| Favorites / watchlist | Low | High | BaT, AutoTrader, Hatla2ee | Foundation for more; smallest lift; drives return visits |
| Vehicle comparison (full) | Low | High | AutoTrader, Carrs | Already partial; fill to side-by-side spec table |
| Search page + filters | High | High | AutoTrader, Cars, Hatla2ee | Category-defining; expected config, faceted |
| Saved searches | Med | High | AutoTrader, Hatla2ee | Drives recurring engagement + notifications |
| Alerts / notifications | Med | High | AutoTrader text alerts, BaT auction alerts | Funnel from saved searches; revenue lever |
| Verified / trust badges | Med | High | Cars dealer rating, BaT curation | Collector buyers buy trust; reduces fraud friction |
| Seller / dealer dashboard | High | High | AutoTrader nVision, Cars dealer app | Monetize via your own seller tiers/subscriptions |
| Seller profiles | Low | High | BaT/Cars pedigree emphasis | Establishes provenance & history |
| Reviews (buyer + seller) | Med | High | Cars dealer reviews / BaT comments | Trust signals; SEO; dispute context |
| Off-messaging (offers, messaging) | High | Med-High | Dubai! chat, FB Messenger, Cars inquiry | Transactional; larger build (chat, offers) |
| Financing calculator | Med | Med | AutoTrader loan calculator, Hatla2ee financing | Monthly-payment hook for feasible price anchor |
| Vehicle-history / VIN check | High | Med | CARFAX on BaT/Cap | 3rd-party API; turns trust into premium |
| Transport / shipping quote | Med | Med | BaT/C&B logistics partners | Collector cars are shipped, not driven; biggest value in auctions |
| Sold history / results | High | Medium | BaT results archive, C&B sold | Pricing authority; requires volume to be credible |
| Auctions (reserve/no-reserve) | High | Med | BaT, Cars & Bids | Exponential growth option; complex escrow/fee code |
| Analytics | High | Med | AutoTrader nVision | Business intelligence; need guidelines; ROI tracking |
| Insurance | Low | Med | KBB Insurance UX | Low effort but low near-term revenue for collector niche |
| Blog / editorial | Low | Med | BaT Bulletin | Already have journal; SEO + authority |
| Cross-platform / multilingual | Med | — | Hatla2ee AR/EN | Time EU/African reach |

**High-value, relaunch-effort order (effort ÷ value):** watchlist/favorites → comparison → search+filters → saved searches → alerts → trust badges → buyer reviews → seller dashboard → messaging/offers → VIN history → auctions/sold history → transport & finance.

### Notes & coverage caveats
- Most claims are as OBSERVED on official public pages (see sources above); a few are STRONGLY INFERRED from docs let / seller help pages.
- Facebook Marketplace is intentionally sparse vs has rail platforms: it winning on reach, free, and messaging but lacks structured trust, history, comparison/flance tooling — a core differentiator opportunity for a niche premium marketplace.
- Regional platforms (Dubizzle, Hatla2ee) show that finance-dependent features (financing, insurance, car evaluation) are region-specific and can move marketplace context.
